## Qué cubro

- Separar lógica de datos (hooks/fetching) de componentes de presentación
- Componentes pequeños, con una sola responsabilidad visual
- Estados de carga/error explícitos en toda vista que dependa de datos remotos
- Evitar prop drilling excesivo (context o composición cuando corresponda)

## Cuándo usarme

Antes de crear o modificar cualquier componente o página en apps/frontend.
